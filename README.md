# bodyHOMMAGE

React and Vite recreation of [bodyhommage.com](https://bodyhommage.com/).

## Run locally

```sh
npm install
npm run dev
```

## Images

The hero image is `public/img/hero.jpg`.

Gallery images belong in `public/img/gallery/` and are shown in ascending filename order: `15.png` through `23.png`.

Partner logos belong in `public/img/brand-logos/`. Their display order maps to the original site: Vogue (`11.png`), On (`10.png`), Arc'teryx (`5.png`), UVU Club (`9.png`), lululemon (`2.png`), Nike (`12.png`), adidas (`13.png`), New Balance (`new-balance.avif`), iGNANT (`6.png`), NOHRD (`14.png`), GQ (`8.png`), and Women's Health (`3.png`).

Extra logos in the folder are not shown because they are not on the original site.
